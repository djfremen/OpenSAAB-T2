# K2401 ARM32 installed startup validation — 23 September 2026

The physical K2401 (Android app ABIs armeabi-v7a/armeabi) was updated in place from headunit.17 to signed headunit.19, version code 100019. Existing diagnostic software remained usable without downloading it again. The previous APK was archived privately. Installed version, APK signature and checkpoint SHA-256 were verified: `f52397d638971adc0cd8372d2c517c00b91ee0e2debf19a5b83727008b0e9990`.

Chipsoft J2534 USB 0483:5740 was detected. Connect and start -> Read engine codes completed through the installed UI, showing a fresh model-year-2004 VIN and a complete Trionic 8 current/history report over 500 kbit/s HS-CAN. Optional online lookup was off. No codes were cleared.

P0107 was current; P0122, P0223, P1682, P2122 and P2127 were history. Private evidence comparison confirmed that the VIN and ordered code list matched the fresh Pixel ARM64 result from the same evening. The UI reported USB released and enabled Continue to diagnostic menus. After the repeated ignition confirmation, the native firmware launched; long-press ENTER moved from the original splash to the original Main Menu. The app was left there for the owner.

This is independent ARM32 installed-app evidence for the integrated startup VIN/DTC sequence and firmware handoff. It does not qualify language switching, full-vehicle/all-module behavior, original-menu ECU/DTC retrieval, security access or physical unplug/replug. No controlled startup timing was taken, so this run does not renew the ten-second timing claim.

Raw VIN-bearing logs, screenshots, UI hierarchy and machine-readable receipt are preserved in the private local OpenSAAB test archive, not in this repository. Public APK channels are unchanged.
